# Global Tennis ELO Platform (Upcoming)

## Overview
A free, global rating platform for amateur table tennis players, functioning similarly to Lichess but for physical sports. Players record match results, and the system dynamically recalculates their ELO rating.

## Planned AI Management Contribution
- AI will handle the generation of the core ELO calculation algorithms.
- AI agents will be responsible for setting up the cloud PostgreSQL database and the FastAPI backend architecture.
